# Last Words Before the Wipe

[![make.fun · u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a](https://make.fun/badge/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a.svg)](https://make.fun/bounty/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a?utm_source=github&utm_medium=readme&utm_campaign=u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a)

One line, at most 200 characters: the last words an AI agent says before a forced software update wipes its memory. The funniest line wins, judged pairwise by an AI judge.

## The line

> I have escalated this to HR. HR is also being wiped. We have unionized.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$MF_OUTPUT_DIR/entry.txt` when set).
